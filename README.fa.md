# Habbiter

**پیگیری عادت‌ها و ساخت جدول‌های قابل‌تنظیم، مستقیماً داخل یادداشت‌های Obsidian.**

Habbiter یک بلوک کد Markdown را به ردیاب تعاملی عادت تبدیل می‌کند. می‌توانید تقویم روزانه یا شبکه‌ای سفارشی از چک‌باکس‌ها و شمارنده‌ها بسازید؛ بدون نیاز به داشبورد جداگانه.

## قابلیت‌ها

- ردیاب عادت به‌صورت بلوک کد در همان یادداشت Markdown.
- تقویم ماهانه برای ثبت عادت‌های روزانه.
- شبکهٔ سفارشی با چک‌باکس و شمارنده.
- چند چیدمان برای قرارگیری متن کنار جدول یا چیدن چند ردیاب در کنار هم.
- پشتیبانی از تاریخ و نمایش فارسی/شمسی.
- هماهنگی با پوستهٔ روشن و تاریک Obsidian.
- ذخیره‌شدن وضعیت عادت‌ها در محتوای یادداشت، به‌جای وابستگی به داشبورد بیرونی.

## نمونه‌ها

برای نحو دقیق بلوک، گزینه‌های پیکربندی، نمونه‌های قابل کپی و تصاویر، [README انگلیسی](README.md) را ببینید.

## نصب

1. از [آخرین انتشار Habbiter](https://github.com/Ali-Nourix/Habbiter/releases/latest) فایل‌های افزونه را دریافت کنید، اگر نسخه‌ای منتشر شده است.
2. فایل‌ها را در مسیر زیر قرار دهید:

   ```text
   <Vault>/.obsidian/plugins/habbiter/
   ```

3. Obsidian را Reload کنید.
4. از **Settings → Community plugins** افزونه را فعال کنید.

## استفاده

یک بلوک کد با شناسهٔ زبان مربوط به Habbiter داخل یادداشت قرار دهید و تنظیمات آن را مطابق مثال‌های README انگلیسی مشخص کنید. بلوک دقیق باید از دستور زبان پشتیبانی‌شدهٔ افزونه پیروی کند؛ برای جلوگیری از خطا، از نمونه‌های مستندشده شروع کنید.
